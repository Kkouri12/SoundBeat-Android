# Sound Beat – Android 2.1 Liquid Glass

نسخه‌ی اندروید Sound Beat (Capacitor). ظاهر شبیه iOS/Apple Music:

- **Home** : پلی‌لیست‌ها + Liked Songs، «Recently played» (سری پیش گوش دادی) و «Your songs»
- **Library** : کارت آمار گوش‌دادن + همه‌ی پوشه‌های موزیک گوشی (هر پوشه = یک آیتم)
- **Search** : جستجو توی آهنگ / خواننده / آلبوم / پوشه
- پلیر کامل با پس‌زمینه‌ی بلور از کاور، متن آهنگ سینک‌شده (LRCLIB + Genius، پشتیبانی RTL فارسی)،
  Sleep timer، Lyrics offset، Queue، Shuffle/Repeat
- **Explore حذف شده**، Spotify هم (وابسته به Electron بود)

## نسخه 2.1 — Liquid Glass
- پوسته Liquid Glass با رنگ کاستوم، بلور قابل تنظیم، کاهش افکت‌ها، تم روشن/تاریک و پس‌زمینه دلخواه\n- پنل تنظیمات فارسی/انگلیسی، ادیتور لیریک LRC، دریافت آنلاین و ذخیره آفلاین، ساخت و ذخیره کارت Share Lyrics
- انیمیشن‌های نرم و حالت تمام‌صفحه لیریک در پلیر\n\n## ساخت APK (بدون کامپیوتر، فقط با گیت‌هاب)
1. یه ریپوی جدید توی GitHub بساز و محتوای این پوشه رو آپلود کن.
2. برو تب **Actions → Build APK → Run workflow**.
3. بعد از ~۵ دقیقه، از قسمت Artifacts فایل `SoundBeat-debug-apk` رو دانلود کن، unzip کن و `app-debug.apk` رو نصب کن.

## ساخت روی کامپیوتر
نیاز: Node 18+, JDK 17, Android SDK
```
bash setup-android.sh
cd android && ./gradlew assembleDebug
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```
یا بعد از `bash setup-android.sh` پوشه‌ی `android` رو با Android Studio باز کن.

## ساختار
- `www/index.html` : کل رابط و منطق پخش
- `android-overlay/java/MusicLibraryPlugin.java` : اسکن MediaStore (پوشه‌ها، تگ‌ها) + استخراج کاور
- `setup-android.sh` : پروژه‌ی اندروید رو می‌سازه، پلاگین/پرمیشن/آیکن رو اضافه می‌کنه

## نسخه 3.0
- کنترل پخش از نوتیفیکیشن و قفل‌صفحه (کاور + قبلی/پخش/بعدی + نوار زمان) با `MediaControlPlugin` و `PlaybackService`
- Crossfade (۰ تا ۱۲ ثانیه) و Gapless · پشتیبان‌گیری/بازیابی با یک فایل JSON
- لیریک: اندازه، فونت، حالت تمرکز · کارت Share با چند پس‌زمینه (رنگی، بلور کاور، روشن)
- پریست تم (Aurora / Midnight / Sunset) · بکگراند متحرک از رنگ کاور · Haptic
- ویرایش نام/خواننده/کاور (با جستجوی کاور آنلاین) · نادیده‌گرفتن پوشه‌ها (واتساپ، ضبط تماس)
- دکمه تنظیمات داخل پروفایل · انیمیشن‌های Push/Pop مثل iOS
- رفع باگ: تنظیمات (`put`) به‌خاطر خطای «Assignment to constant variable» هیچ‌وقت ذخیره نمی‌شد

## نسخه 3.1 (ممیزی و رفع باگ)
- **رفع باگ مهم Crossfade:** انیمیشن محو شدن با `requestAnimationFrame` اجرا می‌شد و وقتی صفحه خاموش یا برنامه بک‌گراند بود متوقف می‌شد؛ آهنگ بعدی با ولوم ۰ (سکوت) پخش می‌شد. حالا با تایمر کار می‌کنه
- کاور ویرایش‌شده‌ی دستی حالا روی نوتیفیکیشن و قفل‌صفحه هم نشون داده می‌شه (قبلاً فقط توی خود برنامه بود)
- Haptic و Share/Backup توی APK بدون باندلر هم پیدا می‌شن (`registerPlugin` به‌عنوان جایگزین)
- شماره‌ی نسخه توی «درباره» و پروفایل یکدست شد

### محدودیت‌های شناخته‌شده
- ویرایش تگ فقط داخل برنامه اعمال می‌شه (روی خود فایل آهنگ نوشته نمی‌شه)
- Gapless به‌صورت هم‌پوشانی خیلی کوتاه (۰٫۳۵ ثانیه) پیاده شده، نه gapless واقعی در سطح دیکدر

## نسخه 3.2
- انیمیشن لیریک: اسکرول فنری نرم بین خطوط (با تایمر، قابل قطع با لمس)، حرکت آبشاری خطوط اطراف، و انیمیشن ورود/خروج هنگام رفتن از صفحه‌ی کاور به لیریک و برعکس
- اکولایزر ۵ باند + Bass boost (با Web Audio، بدون کد native) و پریست‌های Flat / Bass / Vocal / Treble
- سرعت پخش (۰٫۵x تا ۲x) · Fade-out در Sleep timer (۱۲ ثانیه)
- ادامه از جایی که ول کردی (صف + موقعیت)، حتی بعد از بستن برنامه
- پیدا کردن آهنگ‌های تکراری (با امکان مخفی کردن هر نسخه) · حالت ماشین (دکمه‌های درشت، صفحه روشن می‌مونه)
- بکاپ خودکار هفتگی + `allowBackup` فعال (بکاپ خودکار اندروید روی اکانت گوگل) + ارسال بکاپ به Drive از طریق Share
- ۳ ویجت صفحه‌ی اصلی: مربعی (کاور)، کارت (کاور + کنترل)، و کپسولی باریک (`SBWidget.java`، فایل‌های `android-overlay/res`)

### ناتمام
- نوشتن تگ روی خود فایل، Android Auto واقعی (نیاز به MediaBrowserService)، و Google Drive مستقیم (نیاز به OAuth)

## نسخه 3.3
- اسکرول لیریک با فنر میراشده‌ی بحرانی (بدون پرش، قابل قطع با لمس) و مرکز‌کردن خط روی وسط خط (برای خطوط چندسطری هم دقیق)
- ساعت لیریک حالا هر فریم به‌روز می‌شه (قبلاً فقط ~۴ بار در ثانیه با timeupdate) → تغییر خط بدون تأخیر و لرزش
- حذف will-change از همه‌ی خطوط (فقط خط جاری) و سبک‌ترشدن ترنزیشن‌ها
- فارسی و انگلیسی یک‌دست: فونت واحد (Vazirmatn)، اندازه‌ی بصری هم‌تراز (فارسی ۷٪ بزرگ‌تر)، line-height و فاصله‌ی یکسان، چینش یکسان برای کل آهنگ (بر اساس زبان غالب)، نرمال‌سازی ي/ك، ارقام، «؟ ،» و نیم‌فاصله‌ی «می‌»، و بزرگ‌کردن حرف اول خطوط انگلیسی
